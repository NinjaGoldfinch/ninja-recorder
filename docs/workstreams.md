# Workstreams

WS0–WS8 are the v2 plan, and their specifications live in the plan
repository's
[`docs/workstreams/`](https://github.com/NinjaGoldfinch/ninja-recorder-v2-plan/blob/a84ea760e1ed50b04fd601ddb25188f1a29cb868/docs/workstreams/README.md). This file lists
the workstreams added to it since, each by permalink, so the specification a
change was built against can still be read after the plan moves on.

## WS9 — VOD review and note-taking

An in-app review loop: objectives, per-game reviews, takeaways, blocks, and a
spreadsheet importer. Additive, and outside both v2.0.0 and v2.1.0
([ADR 0004](https://github.com/NinjaGoldfinch/ninja-recorder-v2-plan/blob/a84ea760e1ed50b04fd601ddb25188f1a29cb868/docs/decisions/0004-add-ws9-vod-review.md)).
