# Design assets

Images embedded in GitHub issues. Nothing here is built or shipped, and this
branch shares no history with `main`.

- `library-row/`: the library row redesign. `before-*` is today's `Row.svelte`
  rendered with today's `app.css`; `after-*`, `anatomy-*` and `row-*` are the
  mockup. Rendered in Chromium with Selawik standing in for Segoe UI. The width
  in each file name is the window width, less 17px for the WebView2 scrollbar.
  Red outlines mark elements drawn past the row's right edge (yellow).
